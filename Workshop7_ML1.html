Building a Predictive Model

In the previous section, you explored a real formulation dataset and looked for patterns. Now we’re going to take the next step:

We’re going to build a machine learning model.

What is Machine Learning?

At its core, machine learning (ML) is about this question: Can we use existing data to learn patterns that allow us to make predictions about new data?

In formulation science, that might mean:

  • Predicting droplet size from formulation composition
  • Predicting whether a formulation will progress
  • Estimating stability from component properties

Today, we’ll focus on something concrete and measurable:

** Can we predict droplet size (size) from formulation composition? **

Step 1: Training vs Testing

Before we build a model, we need to understand something important. If we train and test a model on the same data, we’re cheating.

Instead:

  • We train the model on part of the dataset
  • We test it on data it hasn’t seen before

This helps us evaluate whether the model can generalise.

WebR Creating the training dataset

The first thing to do is to split the dataset into training and testing.

ACTIVITY: Split the data into 80% training data and 20% testing data using the commands below:

Let’s explain these commands…

set.seed(123)

R uses random numbers when we randomly split data. If we didn’t set a seed, every time we ran this code we would get a different split.

set.seed() makes the randomness reproducible, meaning:

  • You get the same random split every time
  • Everyone in the class gets the same result

The number 123 is arbitrary… it just fixes the random sequence.

sample(1:nrow(sedds), 0.8 * nrow(sedds))

This line means:

  • Take all row numbers (1 to 668)
  • Randomly select 80% of them
  • Store those selected row numbers in train_index

So train_index is just a list of randomly chosen row numbers.

train <- sedds[train_index, ]

This means:

  • From the dataset sedds, take the rows listed in train_index
  • Keep all columns (that’s what the blank after the comma means)

So train contains the selected 80%.

test <- sedds[-train_index, ]

The minus sign is important.

-train_index means:

  • Take all rows except those in train_index

So:

  • train = selected rows
  • test = everything else

Together, they make up the full dataset but just split into two groups.

Step 2: Building a Simple Model

We’ll use a method called linear regression, which you’ve already met in Workshop 5 (if you can’t remember this, please go back to Workshop 5 to refresh your memory). We’ll use four formulation variables:

  1. oil_total
  2. surfactant_total
  3. cosolvent_total
  4. API_prop

These are chemically meaningful and all directly related to formulation composition i.e. the amount of oil, surfactant, cosolvent and API in the formulation!

A Quick Summary of What We’ve Learned So Far

Looking at our linear regression model:

  • API proportion (API_prop) appears to have the strongest effect on droplet size (as seen by the largest magnitude for the ‘estimate’: increasing API loading tends to slightly reduce size.
  • Surfactant (surfactant_total) has a weak negative trend, which makes chemical sense — more surfactant can stabilise smaller droplets.
  • Oil (oil_total) and cosolvent (cosolvent_total) don’t show strong effects in this dataset.

However, the overall model is weak:

  • Multiple R² ≈ 0.05 → the model explains only ~5% of the variation in droplet size
  • Residuals are large → predictions will be noisy

Why Are We Still Making Predictions?

Even with a weak model, building predictions is a valuable exercise:

  • It helps us understand how machine learning works in practice
  • It teaches us to interpret model performance and limitations
  • It gives a framework to think about what variables matter and which don’t

So, for the sake of learning, let’s now try using this model to predict droplet size on new formulations.

Note

Remember: the predictions won’t be perfect… that’s exactly why evaluating and interpreting models is important in real research.

RStudio Creating a model in R Studio

The following is a self-contained script that captures everything done so far in order to predict droplet size. Please feel free to copy and paste it into an R script file and save!

# ===============================================
# R Script: Simple ML Exercise — Predicting Droplet Size
# Students can copy this into RStudio and run
# ===============================================

# 1. Load necessary libraries - REMEMBER - you need to have already installed them on R Studio.
library(ggplot2)
libary(dplyr)

# 2. Load the dataset from Canvas
url <- "https://canvas.kingston.ac.uk/files/7079861/download?download_frd=1&verifier=qevlVzIVmy1RcBCNzGftkefQo0CRf8lAtS75rWLW"
sedds <- read.csv(url)

# 3. Inspect dataset
head(sedds)
str(sedds)
nrow(sedds)

# 4. Split data into training (80%) and testing (20%)
set.seed(123)  # Makes random selection reproducible
train_index <- sample(1:nrow(sedds), 0.8 * nrow(sedds))
train <- sedds[train_index, ]
test  <- sedds[-train_index, ]

# 5. Fit a linear regression model
# Predict droplet size from main formulation variables
model <- lm(size ~ oil_total + surfactant_total + cosolvent_total + API_prop,
            data = train)

# 6. Examine model summary
summary(model)

# 7. Make predictions on test set
test$predicted_size <- predict(model, newdata = test)

# 8. Plot predicted vs actual
ggplot(test, aes(x = size, y = predicted_size)) +
  geom_point() +
  geom_abline(slope = 1, intercept = 0, colour = "red") +
  labs(title = "Predicted vs Actual Droplet Size",
       x = "Actual Size (nm)",
       y = "Predicted Size (nm)")

# 9. Compute RMSE
rmse <- sqrt(mean((test$size - test$predicted_size)^2))
cat("RMSE =", rmse, "nm\n")

# 10. Optional: view coefficients directly
coef(model)
